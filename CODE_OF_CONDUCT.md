# Code of conduct

This community welcomes people with different backgrounds and levels of experience. Participate respectfully in issues, pull requests, reviews, discussions and other project spaces.

## Expected behavior

- Be considerate and constructive. Discuss technical decisions with evidence.
- Respect differing views and accept good-faith corrections.
- Help others reproduce problems without requesting private credentials or unnecessary personal information.
- Respect application users' privacy, consent and security boundaries.
- Give proper credit for code, research and other contributions.

## Unacceptable behavior

Harassment, personal attacks, discrimination, threats, sexualized attention, doxxing, publishing private information without permission, credential solicitation, and deliberate disruption are not acceptable. Do not use this project to target people or evade another party's authorization.

## Reporting and enforcement

Report a conduct concern privately to the project maintainer through an available private GitHub channel. If none is available, post a minimal issue requesting a private contact method without naming affected people or exposing details. Use [SECURITY.md](SECURITY.md) for technical vulnerabilities.

Maintainers may edit or remove harmful content, request a correction, close a discussion, restrict participation or remove a contributor when necessary to protect the community. Enforcement should be proportionate and privacy-preserving; concerns about a maintainer can be raised with another available repository maintainer.

This policy applies to project-managed spaces and to public representation of the project. It does not grant permission to collect private information or claim affiliation with OpenAI or DeepSeek.
